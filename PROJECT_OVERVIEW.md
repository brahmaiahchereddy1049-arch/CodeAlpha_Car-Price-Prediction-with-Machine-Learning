# Project Overview

## Problem Statement
Predict the selling price of a used car from its available vehicle characteristics.

## Objective
Build and compare regression models and select the best-performing model on a held-out test set.

## ML Workflow
1. Data loading
2. Data cleaning
3. Feature engineering
4. Train/test split
5. Categorical encoding
6. Model training
7. Model evaluation
8. Model selection
9. Prediction
10. Visualization

## Skills Demonstrated
- Python programming
- Pandas data manipulation
- Feature engineering
- Categorical encoding
- Regression
- Model evaluation
- Data visualization
- Model serialization with Joblib
- GitHub project organization
